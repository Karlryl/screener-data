# Blind-Coding-Kit FEM-SEC-US@1.2.0 V2

Dieses Paket ersetzt keine zwei unabhaengigen Menschen. Es beweist aber bytegenau, dass beide denselben eingefrorenen Fall- und Quellenbestand erhalten haben.

1. Fallmanifest, Quellenbuendel und diese Coding-Regeln auf origin/main committen.
2. Run-Binding auf diesen bereits existierenden Kandidaten-Commit mit den exakten Pfaden, Hashes, Korpus-Hash und Freeze-Zeitpunkt ausfuellen; beide persoenlichen Atteste binden seinen Byte-Hash.
3. Beiden Menschen getrennt exakt dasselbe Paket geben; keine spaeteren Quellen, Kurse, GQS-Daten oder Outcomes.
4. Jeder Mensch fuellt eine eigene coder-Datei und ein eigenes persoenliches Attest aus.
5. Erst nach Abschluss beider Dateien den Verifier ausfuehren. Ein LLM oder derselbe Mensch in zwei Durchlaeufen ist unzulaessig.

Ein PASS entsteht nur, wenn lineares und quadratisches gewichtetes Cohen-Kappa je Dimension mindestens 0,70 erreichen und die gesamte exakte Uebereinstimmung mindestens 0,80 betraegt. Der leere Vorlagenzustand ist absichtlich RED.
